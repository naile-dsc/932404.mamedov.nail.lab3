# Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid

**Выполнил:** Мамедов Наиль Закирович  
**Группа:** 932404  

## Описание проекта
Данный проект является продолжением работы над макетом страницы. Основная цель — практическое освоение Flexbox для создания одномерных макетов и CSS Grid для двумерных, а также применение принципов адаптивной вёрстки[cite: 8].

## Выбранный вариант
**Вариант 16.** Тема «Предприниматель и стартапер» (идеи и метрики)[cite: 9].

## Использованные технологии
- HTML5
- CSS3 (Flexbox, CSS Grid, Media Queries)

## Реализованные требования
1. **Flexbox (Навигация и карточки):**
   - Горизонтальное адаптивное навигационное меню[cite: 8].
   - Секция «Идеи стартапов» (4 карточки с названием, проблемой и решением) сверстана через Flexbox[cite: 8, 9]. 
   - Настроено адаптивное поведение карточек: 4 в ряд на десктопе, 2 на планшете, 1 на мобильных устройствах (соотношение 1/2/4)[cite: 9].

2. **CSS Grid (Дашборд):**
   - Секция «Ключевые метрики» (MAU, LTV, CAC) сверстана через Grid-сетку[cite: 9]. 
   - Настроено адаптивное поведение сетки: 3 колонки на десктопе, 2 на планшете, 1 на мобильных устройствах (соотношение 1/2/3)[cite: 9].
   - Внутри блоков в качестве графиков-заглушек использован семантический тег `<meter>` для визуализации показателей[cite: 9].

3. **Адаптивность и доступность:**
   - Настроены медиа-запросы (`@media`) для планшетов и мобильных телефонов[cite: 8, 10].
   - Отсутствует горизонтальная прокрутка страницы[cite: 8].
   - Для карточек использованы семантически верные теги `<article>`[cite: 8].
   - Контрастность текста и фона соответствует стандарту доступности (≥ 4.5:1)[cite: 8].
